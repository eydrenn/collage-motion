# Fonts

`anton-latin-400.woff2` is Anton (regular, Latin subset), by The Anton Project Authors, from https://github.com/googlefonts/AntonFont. It is licensed under the SIL Open Font License, Version 1.1, and a copy of that license (`OFL.txt`) must be kept next to the font file.

`../metrics.json` holds the advance width of each letter and the cap height, measured from this file. If the font changes, the widths must be measured again.
